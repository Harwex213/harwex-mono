Гексы и типы земли

Остров — связная группа гексов. Один гекс держит одно здание. У гекса есть тип, и тип — первый фильтр строительства: лесопилка встанет только в лесу, шахта — только на жиле. Здание, для которого на острове нет земли, физически недоступно, сколько бы ресурсов ни лежало на складе.

Жёсткая гарантия генератора. Стартовая плита обязана содержать минимум два лесных гекса. Лесопилка ставится только в лесу, лес берётся только экспансией, а экспансия стоит дерева. Старт без леса запирает забег насмерть — это уже случилось на прототипе v1. Проверка вынесена в тесты генератора, не в ревью дизайнера.

Соседство

У гекса шесть соседей. Каждое здание имеет ровно одно правило соседства. Правило считается в момент постройки и пересчитывается, когда рядом появляется или исчезает здание. Бонус подсвечивается на призраке здания до подтверждения покупки — игрок видит цифру раньше, чем платит.

Форма правилаПримерТипичный потолок
За каждый соседний гекс типа XЛесопилка: +0,6 дерева за каждый соседний лес+3 при трёх лесных соседях
За каждое соседнее здание категории YРынок: +1 золото за каждое соседнее добывающее здание+3
За каждый пустой соседний гексПлац: +8% скорости атаки армии за каждый пустой сосед+24%
Штраф за скученностьХижины: −15% лимита, если все шесть соседей застроены−15%

Категории зданий для правил соседства: Добыча, Экономика, Военное, Оборона, Особое.

Зачем это нужно. Соседство превращает застройку из списка покупок в задачу раскладки. Игрок думает не «что купить», а «куда поставить, чтобы не испортить три будущих места». Это главный источник глубины в экономике и единственная причина, по которой карта из гексов лучше карты из клеток: шесть соседей читаются с экрана, восемь — нет.

Разделение источников — ключевое решение экономики. Ресурсы капают со зданий, ОР падают только с трупов. Игрок, который строит и не дерётся, упирается в потолок развития. Игрок, который дерётся и не строит, не может позволить себе армию. Одно без другого не работает — и это гарантирует, что обе половины игры используются.

Потолок склада — четвёртое средство против пустого ожидания. Сверх потолка дерево и кристалл капают вдвое медленнее. Копить впрок наказуемо, тратить — выгодно.

Стартовые значения: 320 золота, 220 дерева, 0 кристалла. Ядро даёт +2 золота и +0,5 дерева в секунду. Полсекунды дерева с ядра — страховка: если волна снесёт все лесопилки при пустом складе, отстроиться будет не на что, и забег закончится без боя.

Экспансия

Земля приходит плитами. Плита — семь гексов: центр и шесть соседей. Типы внутри плиты генерируются, но игрок видит их заранее, если построен маяк.

  1. Построил двигатель острова.Без него остров не двигается вообще. Двигатель требует рынка — то есть работающей экономики.
  2. Выбрал плиту и заплатил.Цена растёт с числом уже взятых плит: золото 120 + 90×n, дерево 60 + 50×n.
  3. Перебил стражей.На плите стоят стражи — их тем больше и они тем крепче, чем дальше плита от старта. Пока стражи живы, захват не идёт. Это работа для армии, а не для золота.
  4. Подождал стыковки — 6 секунд.Волны в это время не останавливаются. Экспансия всегда происходит в окне риска, и окно выбирает игрок.

Пять плит — целевой размер острова к концу забега. Больше семи гексовых плит экран перестаёт вмещать без неудобного зума, поэтому шестая и дальше стоят непропорционально дорого и берутся только в специализации по ветке Ветра.

Дерево развития

Четыре ветки по шесть узлов. Полное закрытие ветки стоит 30 ОР. За забег игрок зарабатывает 55–70 ОР — значит, закрывает две ветки из четырёх. Это и есть специализация билда.

Правило узлов. Каждый средний узел открывает здание, а не только процент. Проценты не меняют то, как игрок играет, — здания меняют. Ветка, состоящая из одних процентов, вырезается.

Известная ловушка баланса. На прототипе v1 экономика дважды ломалась в противоположные стороны: сначала забег запирался по дереву, затем игрок копил 2000 неиспользуемого золота при нуле дерева. Оба ресурса должны быть узким местом попеременно, а не один всегда. Автотест баланса гоняет бота по 200 забегов и валит сборку, если любой ресурс простаивает выше потолка дольше 90 секунд подряд.
