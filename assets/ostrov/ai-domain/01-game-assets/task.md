Game Design Document:
[GDD](/docs/ostrov/01-gdd/gdd.md)

Прочитай GDD и создай список необходимых спрайтов для игры. Для каждого спрайта создай промпт для генерации в ChatGPT Images game-ready спрайта. Дальше создай для каждого спрайта изображение по получившемуся промпту. Используй субагентов для генерации промптов и изображений.

Структура вывода:
- `ostrov-spritesheet.html` - список всех спрайтов в игре, хранит ссылки на получившиеся изображения
- `sprites/${sprite}-{n}.png` - папка `sprites` со всеми спрайтами пронумерованными по порядку

Правила работы:
- Работай автономно, не задавай вопросов пользователю пока не выполнишь задачу
- Работай только в папке, где лежит файл с инструкциями для выполнения
- Не ищи другой контекст, используй только то, что описано здесь
