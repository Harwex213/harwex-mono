# Картинки через Codex

У Claude своей генерации картинок нет, у Codex CLI есть: встроенный `image_gen` (фича
`image_generation`, stable, включена по умолчанию). Работает от подписки Codex,
`OPENAI_API_KEY` не нужен. Проверка: `codex features list | grep image_generation`.

Скилл вырос из `olympus-royale/.claude/skills/asset-refs` (рефы под Tripo) и обобщён:
тот же обвес, но пресетом выбирается, ЧТО за картинка.

## Команда

```bash
# голый промпт
bash .claude/skills/image-gen/scripts/gen-image.sh <out.png> "<описание>"

# референс позы/жеста для аниматора, с персонажем из рендера
PRESET=pose REFS="ArtSource/Animations/references/<рендер-персонажа>.png" \
  bash .claude/skills/image-gen/scripts/gen-image.sh ArtSource/Animations/references/stop.png "<поза>"

# крупный план кисти
PRESET=hand bash .claude/skills/image-gen/scripts/gen-image.sh .../hand-fist.png "<кисть>"

# правка готовой картинки
EDIT=src.png bash .claude/skills/image-gen/scripts/gen-image.sh out.png "убери фон, объект не трогай"
```

Один прогон 1–3 минуты — в Bash `timeout: 400000`, пачку — `run_in_background`.
Не больше четырёх параллельно.

| `PRESET` | Что это | Формат | Альфа |
|---|---|---|---|
| `raw` (по умолчанию) | промпт как есть | square | нет |
| `pose` | поза тела для аниматора: вид 3/4 спереди-справа, кисти крупно, серый фон | portrait | нет |
| `hand` | одна кисть крупно: какие пальцы прямые, какие в ладони, где большой | square | нет |
| `asset3d` | ортографический кадр под image-to-3D, T-поза, пустые руки | square | да |
| `texture` | бесшовная текстура, вид сверху, плоский альбедо | square | нет |
| `concept` | концепт окружения | landscape | нет |
| `ui` | иконка/элемент интерфейса | square | да |

Прочие переменные: `ASPECT=square|landscape|portrait`, `ALPHA=1|0`, `STYLE="..."`,
`REFS="a.png b.png"` (референсы стиля/персонажа, в промпте помечаются как НЕ цель
правки), `EDIT=src.png` (правка вместо генерации).

## Что важно знать

- **Промпт уходит через stdin.** `-i` у `codex exec` жадный (`<FILE>...`) и съедает
  промпт, стоящий после него, как ещё одну картинку — Codex отвечает «No prompt
  provided». Скрипт это учитывает; при ручном вызове с `-i` делай так же.
- **Явный `./имя.png` обязателен.** Иначе оригинал остаётся в
  `$CODEX_HOME/generated_images/<сессия>/`, и скрипт честно скажет, что файла нет.
- **«Do not write any code»** — без этой фразы Codex иногда рисует картинку PIL-ом.
- **Персонажа давать референсом.** Без `REFS` Codex рисует абстрактного человека с
  длинными руками. Для жестов обезьяны — рендер обезьяны v2
  (`iterations/014-hand-gestures-and-actions/tp-dance.png`).
- **Ракурс для жестов — сбоку-спереди.** Рука, вытянутая в объектив, укорачивается
  до точки, и по картинке уже не понять, прямой ли локоть. Пресет `pose` это задаёт.
- **Смотреть глазами, а не верить.** Codex пишет «saved» и тогда, когда картинка
  мимо брифа. `Read` каждую картинку. Для прозрачных — сначала
  `node .claude/skills/image-gen/scripts/preview.mjs <png>` (композит на белом:
  просмотрщики показывают RGB прозрачных пикселей, и годный кадр выглядит как брак),
  `check-alpha.mjs` скрипт запускает сам.
- **Правь одну вещь за прогон**, а не переписывай промпт целиком.

## Куда класть

Картинки-референсы — в `ArtSource/` (`Animations/references`, `Images/`,
`Models/references`; Unity туда не смотрит). В `Assets/_Project/Domains/<Domain>/` —
только то, что реально идёт в игру (текстуры, иконки UI), и это уже решение задачи,
а не этого скилла. `*.preview.png` — мусор, в git не идут.

## Если не получилось

- *Codex написал код* — пропала фраза про «do not write any code».
- *Файла нет* — нет явного `./имя.png`, или путь вне `-C` (скрипт ставит `-C` в
  каталог вывода сам).
- *«No prompt provided via stdin»* — промпт передан аргументом после `-i`.
- *Картинка не про то* — усилить ОДНУ формулировку: чаще всего это ракурс или
  положение пальцев, их надо описывать анатомически («указательный прямой, три
  остальных прижаты к ладони, большой лежит поверх среднего»), а не названием жеста.
