# T01 — think agent handoff

Design: `.plan/T01/DESIGN.md`. It gives full file contents; follow it literally.

## Decided, with reasons

- **No edit to `javascript/package.json`.** The workspace glob is `packages/**/*`,
  which already matches this package. Registration is just creating
  `PKG/package.json` and running `yarn install` from `javascript/`.
- **Every pinned version is already in `yarn.lock`** (react 19.2.0, react-dom
  19.2.0, `@preact/signals-react` 3.9.0, rspack cli/core 2.1.4, dev-server 2.1.0,
  types 19.2.0, typescript 5.9.3, tsx 4.19.4). So `yarn install` adds one
  workspace entry and needs no network. If the lock churns beyond that, a version
  was mistyped.
- **`@rspack/dev-server` is 2.1.0, not 2.1.4.** That is what the reference pins.
  Not a typo — leave it.
- **Added `tsx` 4.19.4 + `"test": "tsx --test \"src/**/*.test.ts\""`** beyond the
  reference package. PLAN section 4 mandates them. This is the only dependency
  addition past what the reference has, flagged here per the rules.
- **`@preact/signals-react` is declared but unimported in T01.** The placeholder
  reads no signals, so `App` does **not** call `useSignals()`. Opt-in per component
  is the convention; a reviewer may flag the unused dep — it is deliberate.
- **`env.d.ts` drops the reference's `declare const process` block.** Nothing in
  T01 reads `process.env`. Re-add it when a task needs it.
- **`src/index.css` is copied verbatim from `../civitas-map`.** The token block is
  the base T08 builds the EU shell on. Do not retune the palette now.
- **`devServer.static` points at `./assets` under `/assets`**, mirroring the
  reference. Production asset delivery is explicitly T02's call — do not add
  `CopyRspackPlugin` or import a PNG from `src`.

## Surprises worth knowing

- The **repo root `.gitignore` already ignores `dist`** (line 5), so the
  package-level `.gitignore` the brief asks for is redundant. Design keeps it as a
  one-liner because it was an explicit deliverable, but nothing breaks without it.
- `node --test "src/**/*.test.ts"` with **zero matching files exits 0** on Node
  24.13.1 (verified by running it). So the `test` script is safe to ship before any
  test exists.
- `type: "javascript/auto"` on the ts rule in the rspack config is load-bearing;
  it is easy to read as noise and drop.
- `index.html` needs both `id="root"` and `class="root"`. `index.css` sizes
  `.root` to `height: 100%`, which the full-screen map in T03 depends on.
- The reference package has no `.gitignore`, no README-adjacent config, and its
  `tsconfig.json` is standalone — it does not extend `@hw/typescript-config`.
  Do not "improve" this by wiring the shared config.

## Trap for the implementer

`noUnusedLocals` + `noUnusedParameters` are on. The placeholder `App.tsx` imports
only `styles`. Any leftover scaffolding import fails `yarn typecheck`.

### `src/scaffold.test.ts`

T01 shipped no runtime logic, so the regression surface is the contract itself.
Every case maps to a failure mode named in DESIGN section 13.

- Manifest identity: name `@hw/civitas-interactive-map`, `private`, `type: "module"`.
- **Every version matches `/^\d+\.\d+\.\d+$/`** — DESIGN 13.2. `defaultSemverRangePrefix: ""`
  only governs `yarn add`; a hand-written `^` survives verbatim and drifts the
  resolution away from `../civitas-map`.
- The pinned versions themselves, including `@rspack/dev-server` at **2.1.0** not
  2.1.4. A "fix" to 2.1.4 fails this test, which is the intent.
- The `test` script string, escaped glob included — DESIGN 13.7.
- tsconfig: no `extends`, no `paths`, `strict`/`noUnusedLocals`/`noUnusedParameters`,
  `jsx: "react-jsx"`, `moduleResolution: "bundler"`, `lib`, `include: ["src"]`.
- `env.d.ts` declares `*.module.css` **before** `*.css` (longest-match resolution).
- `index.html` keeps both `id="root"` and `class="root"`, and `index.css` styles
  `.root` — DESIGN 13.8 plus the height chain T03 needs.
- **No file in `src` imports from `assets/` or imports a `.png`/`.jpg`** — DESIGN 13.6.
  This is the guard that keeps `dist` at 196K. It fires the moment someone shortcuts
  T02's asset decision.
- Convention check over every non-`.d.ts` file in `src`: no `export default`, no
  inline `export const|function|class|interface|type`. `.d.ts` is exempt because
  `declare module "*.module.css" { ... export default classes; }` is legitimate.
- `rspack.config.mjs` is **imported and asserted as an object**, not string-matched,
  so formatting changes do not break it. Pins `namedExports: false` +
  `exportsConvention: "camel-case-only"` (both needed for `styles.someClass`),
  `type: "javascript/auto"` on the ts rule (DESIGN 3 — without it the automatic JSX
  runtime import breaks), `runtime: "automatic"`, `devServer.port: 0`, and the
  `./assets` -> `/assets` static mapping.
  The specifier is computed (`new URL(...).href`) so `tsc` leaves the `.mjs` out of
  the program — tsconfig has no `allowJs`, and a literal specifier would fail typecheck.

### `src/assets.test.ts`

`readPngSize` is a private pure parser inside the test file: signature check, IHDR
check, two big-endian `getUint32` reads. **It is not exported and there is no source
module for it** — DESIGN 15 puts asset loading in T02. It exists so the PNG dimension
facts are proven from the bytes, not restated from the plan. Three of its tests run on
hand-built synthetic buffers (valid header, bad signature, non-IHDR first chunk).

Facts pinned:

- `provinces_map.png` is **3653 x 2855** — read from IHDR.
- `map.png` is **3652 x 2855**: same height, exactly 1 px narrower. Asserted as
  `MAP_WIDTH - art.width === 1`, so it fails if the gap ever widens.
- `manifest.map.{width,height}` equals the PNG's real size.
- `format === "civitas.province-map"`, `version === 1`.
- **1648 provinces**, every one `kind: "land"`.
- **Ids are unique but NOT contiguous: max id is 1650 with 1648 provinces**, so two
  ids are missing. This was not in the plan — I found it while checking the data.
  **T02 must index by a `Map<id, province>`; `provinces[id - 1]` returns the wrong
  province.** The test asserts `maxId === 1650` and that the last element's id is not
  1648, so the trap cannot be forgotten.
- All 1648 packed RGB values are distinct — the colour lookup table cannot collide.
- Every `rgb` triple decodes from its own `hex`.
- Province 1 asserted field-for-field against the PLAN section 2 sample.
- Geometry invariants across all 1648: bounds inside the map, positive extent,
  centroid an integer pixel inside its own bounds, `0 < pixelCount <= width * height`.
- **Centroid is centre of mass, not bbox centre.** 1277 of 1648 centroids sit more
  than 1 px off their bbox centre; the test asserts the exact count and that it
  exceeds half the set. A manifest regenerated with bbox centres would score near 0.
  Sample: province 1's bbox centre is (595, 392.5), its centroid is (598, 391).
- `sum(pixelCount) === painted.pixelCount === 2756578`, `unregisteredColors` empty.
- `map.width * map.height === 10429315` and `painted.pixelCount / area` matches the
  declared `coverage` 0.264311 within 1e-6.
- Every name is exactly `"Province <id>"`, all distinct, and the manifest contains no
  `"country"` key — there is no country data anywhere, per PLAN section 2.

### Deliberately not covered

- **DOM, canvas, React.** No jsdom in this repo. `App.tsx`, `main.tsx` and the
  `createRoot` mount are untested by design.
- **`yarn install` / lockfile state.** DESIGN 13.1 and 13.4 (workspace not picked up,
  `@rspack/core/module` missing) are install-time failures. A test asserting on
  `yarn.lock` would be a slow, flaky duplicate of `yarn typecheck` itself.
- **`dist/` contents and bundle size.** Asserting on build output would make the test
  suite depend on a prior `yarn build`. The `src`-imports-no-assets test covers the
  same regression (DESIGN 13.6) at its cause instead of its symptom.
- **The "no single-quoted strings" rule.** A regex over source would false-positive on
  apostrophes in comments and JSX text. The no-default-export / no-inline-export half
  of the convention is checked because it can be matched safely at line starts.
- **Pixel contents of the PNGs.** Only the IHDR header is parsed. Decoding 3653x2855
  RGBA needs an image decoder, which is T02's dependency decision, not this task's.
- **`src/index.css` token values.** DESIGN 10 says copy verbatim and do not retune;
  asserting each custom property would freeze a palette T08 is expected to build on.
  Only the presence of a `.root` rule is checked, because the height chain depends on it.
