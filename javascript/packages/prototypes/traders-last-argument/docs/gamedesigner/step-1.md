# СТЕП 1. Карта

Краткие сведения:

- 2D-сетка (тайловая карта) 100 на 100. Каждый квадрат 50 пикселей (нужна переменная).
- Карта состоит из двух видов клеток: Плодородная земля и Гора.
- На каждой клетке может быть два объекта: Дерево или залежи Камня
- Клетки - цветные квадраты. Объекты и сущности - иконки.
- Сущности пока не реализовываем
- Камеру можно двигать/зумить в пределах мира (100 * 50 = 5000 пикселей)
- Карта генерируется алгоритмом perline noise. Следуй концептам [этой](https://www.redblobgames.com/maps/terrain-from-noise/) статьи, чтобы создать алгоритм генерации интересной карты.
