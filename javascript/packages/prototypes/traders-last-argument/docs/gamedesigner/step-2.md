# СТЕП 1. Пешки

Краткие сведения:

- Пешка - сущность на карте
- Пешка имеет показатель здоровья
- Пешка имеет имя (генерируется автоматически при создании пешки)
- Пешка передвигается со скоростью примерно 1 клетка в секунду
- Пешку можно выбрать, откроется панель с информацией о ней
- На старте у игрока 5 пешек
- Игра симулирует реальное время, тики идут постоянно
- Игру можно поставить на паузу
