# @hw/faenwald-battle-prototype-themes

Витринные темы боевой системы Фенвальда. Одна тема — один самодостаточный
`.html` файл: вся вёрстка, стили и данные лежат внутри него, а рядом только
портреты отрядов. Так две темы можно открыть в соседних вкладках и сравнить,
ничего не собирая.

```bash
yarn workspace @hw/faenwald-battle-prototype-themes dev   # http-server, случайный свободный порт
```

## Темы

- `battle-v2.html` — **«Витраж»**. Стёкла в свинцовом контуре, готические арки,
  роза за заглавием. Взято из варианта В промптов аватарок
  (`faenwald-battle-prototyp-v2/assets/units-avatars-prompts`), поэтому фон и
  портреты читаются как одно окно.
- `battle-v1.html` — первый подход к тому же витражу, оставлен для сравнения.

## Как собран витраж

Ни одного внешнего запроса: ни шрифтов, ни картинок помимо портретов.

- **Свинцовая рама** — два вложенных элемента с одной и той же формой:
  внешний залит свинцовым градиентом, внутренний обрезан на 5 пикселей внутрь.
  Классы `.came` / `.came-in`.
- **Готическая арка** — `clipPath` в объектных координатах
  (`clipPathUnits="objectBoundingBox"`), поэтому одна форма годится и для
  створки в 372 пикселя, и для карточки в 172. Формы `#arch-tall` и `#arch-low`.
- **Роза-окно** в заглавии — настоящий SVG: один лепесток, размноженный
  шестнадцатью поворотами. Свинцовые рёбра должны быть путями, иначе они не
  выдержат медленного вращения.
- **Мозаичное стекло** (`.rose-field`) — клинья `conic-gradient` с жёсткими
  остановками, поверх них свинцовые лучи и кольца из `repeating-conic-gradient`
  и `repeating-radial-gradient`. Между двумя цветами у настоящего стекла стоит
  свинец, а не растяжка, поэтому переходов здесь нет. Отдельный слой чередует
  светлоту колец — без него клин читается одной полосой.
- **Ромбовидное остекление** (`.quarry`) — quarry glazing на панелях текста.
  Самоцвет панели задаётся переменной `--glass`.

## Данные

Ростер лежит в `<script>` внутри темы: тринадцать отрядов, цифры и описания из
`faenwald-battle-prototyp-v2/assets/units-avatars-prompts` — по одному файлу на
отряд. Инженеры в той таблице есть, но картинки у них пока нет, поэтому в теме
их не видно.

Очередь раунда собрана по запасу хода: пять гексов идут первыми, один —
последним. Это не отдельные цифры инициативы, а тот же порядок, что описан в
README прототипа v2 — лёгкий отряд ходит раньше тяжёлого.

## Портреты

`assets/units-avatars/` — копии 256-пиксельных нарезок из
`faenwald-battle-prototyp-v2/assets/units-avatars/`. Копии, а не ссылки: тема
поднимается статическим сервером из своей директории, и путь `../` за корень
сервера не выйдет. Обновить нарезку:

```bash
cp ../faenwald-battle-prototyp-v2/assets/units-avatars/*-256.png assets/units-avatars/
```
