1. Approach

Following the research verdict: hand-roll simple components, use Radix Primitives for complex interactive behaviors.

  • All components styled with CSS Modules, consuming design tokens from tokens.css
  • Each component lives in src/ui/kit/ as a .tsx + .module.css pair
  • Simple components (Button, Input, Checkbox, IconButton) — pure React, no dependencies
  • Complex components (Dialog, Select, Tooltip, Popover) — Radix Primitives for behavior, CSS Modules for visuals

3. Hand-rolled Components

Pure React + CSS Modules. No external dependencies.

Button

Variants: primary (gold accent), secondary (white-alpha), ghost (transparent). Props: variant, size (sm | md), disabled, children.

Replaces raw <button> elements throughout the app.

IconButton

Square button for icon-only actions (navigation arrows, add, toggle). Props: size (sm | md), disabled, children (icon content).

Replaces .navButton and .addButton in event timeline, debug panel toggle.

Input

Text/number input with optional label. Props: label, type, value, onChange, standard input attributes.

Replaces raw <input> in debug panel.

Checkbox

Custom-styled checkbox with label. Props: label, checked, onChange.

Replaces native checkbox in debug panel.

Card

Overlay container matching the existing dark translucent style. Props: children, optional className for positioning.

Extracts the shared pattern from selected province / hovered province / selected army panels.

ScrollArea

Wrapper with styled scrollbar (thin, dark-themed). Props: direction (horizontal | vertical), children.

Replaces overflow-x: auto and overflow-y: scroll patterns.

4. Radix-backed Components

Use Radix Primitives for accessible behavior. All visuals via CSS Modules.

Dialog

Install: @radix-ui/react-dialog

Wraps Radix Dialog with project styling: dark overlay, centered content panel, close button. Provides DialogTrigger, DialogContent, DialogTitle, DialogClose re-exports with applied CSS Modules.

Needed for: event editing modal (click event card → open details), add event form.

Select

Install: @radix-ui/react-select

Wraps Radix Select with dark-themed trigger, dropdown, and option items. Keyboard navigation and typeahead built in.

Needed for: event type picker when creating events, army/province selection in event forms.

Tooltip

Install: @radix-ui/react-tooltip

Wraps Radix Tooltip. Dark compact style with arrow. Delay on hover.

Needed for: button labels on icon-only buttons, map UI element hints.

Popover

Install: @radix-ui/react-popover

Wraps Radix Popover for anchored floating panels. Dark-themed, with arrow and outside-click dismiss.

Needed for: contextual actions, quick-edit panels, future province/army context menus.

6. Implementation Priority

Ordered by immediate need and dependency chain:

Priority Component Reason

P0 Input, Checkbox Debug panel already uses raw inputs. Event editing will need them immediately.
