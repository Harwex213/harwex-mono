# Лёгкий копейщик (ЛКо)

**Роль:** копейщик. Держит строй в плотной формации.
**Матчасть:** копьё и деревянный щит-рондаш. Стёганка и очень простой шапель. Брони фактически
нет — прекрасная мишень для лучника. Зато самый быстрый из копейщиков.
**Характеристики:** 80 ❤️ / 12 ⚔️ / 70 📯 / 3 гекса / 30 000.
