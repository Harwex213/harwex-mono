pixi-рендер мира: реконсилиация спрайтов, бейк террейна, шейдеры, камера, ассеты. Границы с остальными
пакетами — в CLAUDE.md группы (`../CLAUDE.md`): здесь только внутренние правила рендера.

## Модель работы

- **Реконсилиация, а не подписки:** каждый кадр пул спрайтов сверяется с world — новым создать,
  исчезнувшим удалить, остальным обновить трансформ. Связей sim→render нет, рассинхрониться нечему.
- **Между тиками интерполяция** `lerp(prevPos, pos, alpha)`: sim идёт редко, картинка 60 fps.
- **Выводимое из состояния в состоянии не хранится:** facing — из движения, вариант спрайта — из
  `entityId`, разброс декора — из хеша тайла и seed'а. Стабильно между перезагрузками, вне сейва, без
  миграций.
- **Кадр анимации выбирается по тику, а не по таймеру рендера:** пауза замораживает, ускорение
  ускоряет, детерминизм цел. Самоанимирующиеся спрайты не используются. Фазе шейдера целых тиков мало
  (10 шагов в секунду под 60-fps картинкой) — ей идёт `tick + alpha`, тот же множитель, что лерпит
  спрайты; часы остаются симуляционными. Дискретный ритм — только тому, что должно мигать (блики).
- **Три категории графики:** запечённое (собирается один раз), реконсилируемое (сверяется с world
  каждый кадр), шейдерное (геометрия строится один раз, живёт через uniform'ы).
- **Статичное запекается:** террейн — один битмап на всю карту, скалы — батч-контейнер (тайлмап).
  Ставший интерактивным или добываемым объект переезжает в сущности.
- **Порядок задают только слои и y-сортировка.** Запечённый слой в y-сортировке не участвует: для
  клаттера размером в тайл приемлемо, для крупных объектов нет.

## Бейк террейна

- **Граница террейнов пиксельная, а не тайловая.** Тайл решает только, из чего сделана точка; границу
  бейк считает по арт-пикселям на dual grid — по четырём центрам тайлов вокруг точки. Тайловая
  единица покраски даёт швы по краям тайлов и карту-лоскутное одеяло.
  - Материалы упорядочены **тотально** (вода → берег → песок → трава → сухая высота), старший
    заливает младшего; два оттенка одной земли — два материала, поэтому пятна не квадратные.
  - Порядок даёт вложенные множества покрытия → одно значение шума решает их все; иначе на пиксель
    претендуют двое или никто.
  - Шум берётся в мировых арт-пикселях: пер-тайловый паттерн вернёт тайловый шов.
  - Прямая граница остаётся прямой — бейк снимает квантование по сетке, а не искривляет линию (апрон
    хребта в `divided-lands`).
- **Резкий цветовой шаг лечится квантованными тонами и дизерингом, а не смешиванием:** альфа-градиент
  даёт внепалитровые цвета и на ×8 читается как блюр. Правильный градиент — пара-четвёрка плоских
  тонов плюс статический пер-пиксельный хеш на границе. Без дизеринга возвращаются концентрические
  контуры, с анимированным — кипящий берег.
  - Полоса «песок → вода»: тон — кадр мокрого песка из пака. Кладётся по дистанции от границы, вторым
    проходом по готовому битмапу (ширина — свойство расстояния, известна только когда вся граница
    посчитана). Ширину шатаем шумом, иначе у полосы появляется свой жёсткий край.
  - Пена — оверлей, её тона вне палитры: рамп по той же дистанции, ярко у линии воды, растворяется в
    море.
- **Битмап карты — одна текстура** → карта ограничена лимитом GPU. 64×64 тайла = 1024², бейк ~140 мс
  (половина — два chamfer-прохода по миллиону пикселей). Ответ на рост — чанкинг, не битмап побольше.
- **Скалы (`Cliff.png`) — nine-slice** по четырём соседям того же террейна, тайлмапом поверх
  запечённой земли, а не вместо неё: углы кадров прозрачные. Поэтому гора не заводит своего материала
  в бейке — ей нужна барренная земля, та же, что у `Rock`. Nine-slice покрывает только выпуклый
  контур: массив шириной в тайл рисуется отдельным «камнем» (любой из девяти кадров — стена вдоль
  одной стороны и плато вдоль другой), вогнутые стыки видны как разрыв стены.

## Шейдеры

- **Шейдер — материал слоя, а не постобработка:** рисуется поверх запечённой графики (лист владеет
  базовым цветом, шейдер добавляет движение), считает в мировых (тайловых) координатах — в экранных
  эффект едет при пане и зуме. Пиксельность держим сами: снап к арт-пикселю, квантование в полосы.
- **Форму шейдеру задаёт маска, а не геометрия:** после пиксельной границы сетка квадов «по водным
  тайлам» врёт про воду. Вода — один квад над мокрой частью карты плюс маска-текстура, сухие пиксели
  внутри квада отбрасываются. Маску и заливку печёт один проход, иначе кайма.
- **В маске дистанция, а не тир:** alpha — «здесь вода», red — расстояние до ближайшего сухого пикселя
  (два chamfer-прохода, за кэпом всё открытое море). Сигнал шейдеру обязан быть той же точности, что
  картинка под ним: тайловый тир глубины положит пену только кольцом шириной в тайл.
- **pixi прибит к WebGL** (`preference`): шейдеры только на GLSL, автодетект мог бы поднять
  WebGPU-контекст и молча их выкинуть.

## Камера и вывод

- **Камера — единственный владелец трансформа корневого контейнера.** Zoom якорится на курсоре, pan
  зажат границами мира, offset считается во float и уходит в pixi округлённым — иначе pixel-art
  дрожит при панораме.
- **`nearest` на всех текстурах.**
- **Постобработка — один фильтр на корневом контейнере,** не на stage: грейд палитры правится
  константой, исходная графика и DOM-HUD поверх канваса не затронуты.

## Ассеты

- **Логика — в тайлах:** пиксельный размер тайла — деталь рендера.
- **Раскладка листов описывается один раз** и наружу отдаётся по смысловым осям, не по сырым
  координатам кадра.
- **Текстуры прелоадятся в бутстрапе:** реконсилиация синхронна и ждать загрузку не может.
- **Заливки земли нужны байтами, а не текстурами:** бейк собирает карту попиксельно на CPU, а
  GPU-текстуру обратно не прочитать. Листы заливок декодируются в RGBA через canvas, для пиксель-арта
  с `premultiplyAlpha: "none"`. Спрайт-листы (включая `Cliff.png`) идут обычным путём через `Assets`.
