1) Всё начинается с того, что есть `contract.ts` - в нём typescript types компонентов
2) Дальше есть React Provider конкретного UI Kit - `ui/index.tsx`
3) Конкретный Ui Kit берётся из `vite.config.ts` исходя из env переменной и `aliasing`
4) В папке `adapters` содержатся фасады к конкретным UI Kit

Вывод: подвязываемся на конкретный один UI Kit во всех новых проектах. Когда понадобится действительно новый UI Kit -> нейроныч скорее всего легчайше произведёт эту замену.
