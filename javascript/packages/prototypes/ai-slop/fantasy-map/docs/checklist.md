# Чеклист тестов (DoD): платформа Faenwald

Прототип считается готовым, когда все пункты отмечены.

## 1. Загрузка карты

- [ ] Пользователь может загрузить PNG файл карты
- [ ] Большой PNG (например, 4096×4096+) загружается без падения приложения
- [ ] Загруженная карта отображается на канвасе
- [ ] Не-PNG файл отклоняется или корректно обрабатывается (нет краша)

## 2. Слой провинций

- [ ] Слой провинций создаётся автоматически в момент загрузки карты
- [ ] Размер слоя провинций совпадает с размером загруженной карты
- [ ] В момент создания слой полностью залит white (`#FFFFFF`)
- [ ] Слой провинций рендерится поверх карты
- [ ] White (`#FFFFFF`) трактуется как «нет провинции»

## 3. Прозрачность слоя

- [ ] Есть контрол изменения прозрачности слоя провинций
- [ ] Изменение прозрачности применяется к слою визуально (0% — слой не виден, 100% — полностью перекрывает карту)
- [ ] Изменение прозрачности не изменяет пиксельные данные слоя (влияет только на отображение)

## 4. Инструмент «Рисовать»

- [ ] Инструмент можно выбрать
- [ ] Рисование применяет текущий цвет провинции на слой провинций (не на карту)
- [ ] Нарисованные пиксели имеют ровно выбранный цвет (без сглаживания/полупрозрачных краёв)
- [ ] Рисование работает при любом уровне прозрачности слоя
- [ ] Рисование за пределами карты не ломает приложение

## 5. Инструмент «Пипетка»

- [ ] Инструмент можно выбрать
- [ ] Клик пипеткой по слою провинций выбирает цвет этой провинции
- [ ] Выбранный цвет становится активным для инструмента «Рисовать»
- [ ] Клик по white-области (`#FFFFFF`) обрабатывается корректно (нет краша; white не становится «провинцией» либо явно определено поведение)

## 6. Кнопка «Новая провинция»

- [ ] Нажатие генерирует новый цвет провинции
- [ ] Сгенерированный цвет уникален (не совпадает с существующими провинциями)
- [ ] Сгенерированный цвет не равен white (`#FFFFFF`)
- [ ] Новый цвет становится активным для инструмента «Рисовать»

## 7. Кнопка «Скачать»

- [ ] Нажатие скачивает два файла: PNG слоя провинций и JSON метаданных
- [ ] PNG содержит актуальное состояние слоя провинций (все нарисованные провинции)
- [ ] PNG не содержит артефактов прозрачности отображения (сохраняются исходные цвета пикселей)
- [ ] JSON содержит метаданные обо всех созданных провинциях (как минимум цвет каждой)
- [ ] JSON валиден (парсится без ошибок)
- [ ] Цвета в JSON соответствуют цветам в PNG

## 8. Сквозной сценарий (e2e)

- [ ] Загрузить карту → создать провинцию → нарисовать её → пипеткой выбрать её цвет → дорисовать → создать вторую провинцию → нарисовать → скачать; оба файла корректны и согласованы
