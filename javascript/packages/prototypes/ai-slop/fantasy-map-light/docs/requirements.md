# Требования: платформа Faenwald

## Исходная идея

Веб-приложение, через которое пользователь загружает игровую карту, чтобы разбить её на провинции и заполнить техническую инфу для правильного рендера провинций и элементов игры

## 1. Роли

1) **Пользователь**

- Загрузить карту (большой PNG файл)
- Менять прозрачность слоя провинций
- Через выбранный инструмент "пипетка" выбирать цвет провинции
- Через выбранный инструмент "рисовать"
- Через выбранный инструмент "ластик" стирать провинции (рисовать white цветом)
- Нажимать на кнопку "Новая провинция", чтобы генерировать новый цвет
- Нажимать на кнопку "Скачать", чтобы скачать два файла: 1) png слой провинций, 2) json метаданные о провинциях
- Отменять/возвращать операции на холсте: `Ctrl (Cmd) + Z` — Undo, `Ctrl (Cmd) + Shift + Z` — Redo
- Масштабировать карту: `Ctrl (Cmd) + Mouse Wheel` или pinch-zoom двумя пальцами на тачпаде

## 2. Бизнес-логика

### Слой провинций

- Представляет собой png, где white (`#FFFFFF`) цвет - отсутствие провинции, а каждая провинция имеет свой собственный цвет
- Должен создаваться в момент, когда пользователь загружает карту
- Слой провинций в моменте создания должен состоять полностью из white цвета

### Инструмент рисовать

- позволяет "рисовать" провинции - изменения должны применяться на слой провинций

### Инструмент пипетка

- позволяет выбрать цвет провинции

### Инструмент ластик

- позволяет рисовать white (`#FFFFFF`) цветом, тем самым удаляя ненужные провинции

### Undo / Redo

- `Ctrl (Cmd) + Z` откатывает последнюю операцию на холсте (Undo)
- `Ctrl (Cmd) + Shift + Z` возвращает откатанную операцию (Redo)
- Единица истории — законченный штрих; новый штрих после Undo сбрасывает ветку Redo

### Zoom

- Масштабирование холста через `Ctrl (Cmd) + Mouse Wheel` ИЛИ pinch-zoom двумя пальцами на тачпаде (для ноутбуков)
- Мотивация: карта может быть большой
- Zoom влияет только на отображение — пиксельный буфер провинций не меняется

### Очистка «мёртвых» провинций

- Если на слое не осталось ни одного пикселя какой-то провинции (закрашена другой, стёрта ластиком, откатана через Undo) — провинция удаляется из реестра
- Удалённая провинция не попадает в экспортируемый JSON; её цвет может быть выдан повторно
