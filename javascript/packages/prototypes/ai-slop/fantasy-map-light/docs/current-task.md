# Текущая задача: улучшения редактора провинций

Источник: `docs/improvement.md`. Ниже — Definition of Done по каждому пункту.

**Статус: реализовано и проверено** (harness на реальном canvas, headless Chrome
— 32/32 PASS; `yarn build` зелёный).

## 1. Undo / Redo

- [x] `Ctrl+Z` (Windows/Linux) и `Cmd+Z` (macOS) откатывают последнюю операцию рисования на слое провинций (Undo).
- [x] `Ctrl+Shift+Z` / `Cmd+Shift+Z` возвращают откатанную операцию (Redo). (Также `Ctrl+Y`.)
- [x] Единица истории — один законченный штрих (от pointer down до pointer up), а не отдельный штамп кисти.
- [x] Undo при пустой истории и Redo при отсутствии откатов ни к чему не приводят и не падают.
- [x] Новый штрих после Undo очищает ветку Redo (стандартная семантика редакторов).
- [x] Undo/Redo корректно восстанавливают пиксели буфера — экспортируемый PNG соответствует видимому состоянию.

## 2. Cleanup dead provinces

- [x] Если после операции (рисование поверх, стирание, Undo/Redo) у провинции не осталось ни одного пикселя на слое — она удаляется из реестра провинций.
- [x] «Мёртвая» провинция не попадает в экспортируемый JSON (инвариант «JSON = фактические цвета PNG» сохраняется).
- [x] Цвет удалённой провинции не считается занятым: `generateUniqueColor` может выдать его повторно.
- [x] Если удалённая провинция была активным цветом кисти — UI корректно это обрабатывает (нет рисования несуществующей провинцией без её пересоздания).

## 3. Zoom

- [x] `Ctrl+Mouse Wheel` (`Cmd+Mouse Wheel` на macOS) масштабирует холст.
- [x] Pinch-zoom двумя пальцами на тачпаде работает (для ноутбуков) — приходит как `wheel` с `ctrlKey`.
- [x] Zoom центрируется на позиции курсора (точка под курсором остаётся на месте).
- [x] Масштаб ограничен разумными пределами (min: карта целиком, max — фиксированный предел), без «улёта» в бесконечность.
- [x] Рисование и пипетка корректно работают при любом масштабе: экран↔карта пересчитываются через актуальный transform.
- [x] Zoom влияет только на отображение — пиксельный буфер провинций не меняется, `imageSmoothingEnabled = false` сохраняется (пиксели чёткие).
- [x] Страница браузера при `Ctrl+Wheel` над холстом не зумится (preventDefault, нативный listener passive:false).

## 4. Eraser (ластик)

- [x] Доступен инструмент/режим, рисующий white (`#FFFFFF`) — то есть стирающий провинции.
- [x] Ластик использует ту же механику кисти (размер, штампы вдоль отрезка, точная запись без AA).
- [x] Стирание всех пикселей провинции запускает cleanup из п.2.
- [x] Операции ластика попадают в историю Undo/Redo.
- [x] Пипетка по стёртой (white) области по-прежнему не создаёт провинцию.

## Общее

- [x] `yarn build` (tsc + vite build) проходит без ошибок.
- [x] Все пункты проверены харнессом на реальном canvas (headless Chrome) — 32/32 PASS.
- [x] Существующий DoD не сломан: загрузка PNG, прозрачность, рисование, пипетка, экспорт PNG+JSON работают как раньше.
