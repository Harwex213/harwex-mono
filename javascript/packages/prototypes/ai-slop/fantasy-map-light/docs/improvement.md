# Что нужно исправить?

## 1 - Undo / Redo

Текущее поведение: Ctrl (Command) + Z (Undo) и Ctrl + Shift + Z (Redo) ни к чему не приводят
Желаемое поведение: Требуется чтобы сочетание клавиш `Ctrl (Command) + Z` делало операцию Undo на холсте и `Ctrl + Shift + Z` делало операцию Redo
Мотивация: Во всех текстовых редакторах поддержана функциональность Ctrl (Command) + Z (Undo) и Ctrl + Shift + Z (Redo) и это удобно

## 2 - Cleanup dead provinces

Текущее поведение: если не осталось ни одного пикселя какой-то провинции, она все ещё остаётся как мусор
Требуемое поведение: если не осталось ни одного пикселя какой-то провинции, она должна быть удалена

# Что нужно добавить?

## 1 - Zoom

Текущее поведение: Zoom не поддержан ни в каком виде
Желамое поведение: Есть возможность делать Zoom на Ctrl (Command) + Mouse Wheel ИЛИ через два touch (для ноутбуков)
Мотивация: Карта может быть большой

## 2 - Eraser

Текущее поведение: невозможно рисовать белым цветом
Желаемое поведение: есть возможность рисовать белым цветом, тем самым удаляя ненужные провинции
