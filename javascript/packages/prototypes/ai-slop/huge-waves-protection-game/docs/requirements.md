# Исходная идея

Игра в браузере. Игрок начинает в центре карты за своего персонажа. На него постоянно идут волны монстров, которые увеличиваются в размере и качестве (иногда в размере, иногда в качестве). Игрок с убийством монстров прокачивает свой уровень. За каждый уровень ему рандомно выпадает три способности на выбор из пула способностей (около 40 штук). Существуют способности, которые позволяет прокачивать уровень.
