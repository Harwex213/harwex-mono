# Backlog — Huge Waves Protection Game

Задачи отсортированы по важности (сверху — самые важные). Категории: `infra` / `feature` / `tech debt`.
Стек: plain HTML + ES modules + Canvas 2D, без шага сборки. Запуск через статический сервер.

Структура кода (контракты между слоями):
- `index.html` — точка входа, `<canvas>`
- `src/main.js` — bootstrap + game loop (fixed timestep)
- `src/core/` — `input.js`, `math.js`, `rng.js`, `state.js` (глобальное игровое состояние)
- `src/entities/` — `player.js`, `enemies.js`, `projectiles.js`, `pickups.js`
- `src/systems/` — `spawn.js` (волны), `combat.js`, `leveling.js`, `abilities.js`
- `src/render/` — `renderer.js`, `camera.js`
- `src/ui/` — `hud.js`, `levelup.js`, `screens.js` (game over/start)

Контракт: системы работают над общим `state` объектом, мутируют его в `update(state, dt)`; рендер только читает `state`.

## T1 — [infra] Скелет проекта и игровой цикл ✅ выполнено
Создать `index.html` с полноэкранным `<canvas>`, `src/main.js` с game loop на requestAnimationFrame и фиксированным шагом симуляции (accumulator, dt = 1/60). Модуль `src/core/state.js` с начальным состоянием, `src/core/math.js` (вектора, clamp, dist), `src/core/rng.js` (seedable). README с инструкцией запуска через статический сервер. Пустой цикл должен чистить и заливать фон canvas без ошибок в консоли.

## T2 — [feature] Игрок: рендер и управление ✅ выполнено
`src/entities/player.js` — персонаж в центре мира, HP, скорость. `src/core/input.js` — WASD/стрелки, нормализованный вектор движения. `src/render/renderer.js` + `src/render/camera.js` — камера следует за игроком, отрисовка игрока и фонового грид-паттерна большого мира. Игрок плавно двигается по миру больше экрана.

## T3 — [feature] Спавн врагов и волны ✅ выполнено
`src/entities/enemies.js` + `src/systems/spawn.js` — враги появляются за краями экрана и движутся к игроку (chase). Волны усиливаются со временем: растёт частота/количество спавна, HP и скорость, появляются новые типы монстров по мере роста таймера. Отрисовка врагов.

## T4 — [feature] Бой: авто-атака, урон, смерть ✅ выполнено
`src/entities/projectiles.js` + `src/systems/combat.js` — оружие игрока автоматически стреляет по ближайшему врагу с кулдауном; коллизия снаряд↔враг наносит урон; враги умирают при HP<=0. Контакт врага с игроком наносит урон игроку (с i-frames/кулдауном).

## T5 — [feature] XP и уровни ✅ выполнено
`src/entities/pickups.js` + `src/systems/leveling.js` — умерший враг роняет XP-гем; игрок подбирает в радиусе притяжения; XP копится, при достижении порога — level up (растущая кривая порога). Событие level-up для UI.

## T6 — [feature] Способности: пул ~40 + выбор при level-up ✅ выполнено
`src/systems/abilities.js` — data-driven пул из ~40 способностей (урон, скорострельность, скорость, HP, доп. снаряды, радиус подбора, XP gain и т.д.), включая влияющие на прокачку. При level-up выдаётся 3 случайных доступных варианта; выбранная способность применяет эффект к state немедленно. Поддержка уровней способности (стакаются).

## T7 — [feature] HUD и экран выбора способностей ✅ выполнено
`src/ui/hud.js` — полоса HP, уровень, полоса XP, таймер, счётчик убийств. `src/ui/levelup.js` — при level-up пауза симуляции и оверлей выбора 3 способностей (мышь + клавиши 1/2/3), применение и снятие паузы.

## T8 — [feature] Game Over и рестарт ✅ выполнено
`src/ui/screens.js` — стартовый экран, при HP<=0 экран Game Over со статистикой (время, убийства, уровень) и кнопкой/клавишей рестарта (полный сброс state).
