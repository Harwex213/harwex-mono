# Definition of Done — Huge Waves Protection Game (MVP)

Игра-выживалка в браузере в жанре Vampire Survivors. Извлечено из `requirements.md`.

## Technical constraints
- [ ] Игра запускается в браузере без шага сборки (plain HTML + ES modules + Canvas 2D)
- [ ] Запускается через статический сервер, есть инструкция запуска в README
- [ ] Код модульный, слои разделены (input / world / entities / systems / render / ui)
- [ ] Игровой цикл на requestAnimationFrame с фиксированным шагом симуляции (детерминированный dt)
- [ ] Нет ошибок в консоли при игре

## Core gameplay (из requirements.md)
- [ ] Игрок стартует в центре карты за своего персонажа
- [ ] Персонаж управляется игроком (WASD / стрелки), движение плавное
- [ ] Камера следует за игроком по карте больше экрана
- [ ] На игрока постоянно идут волны монстров
- [ ] Монстры движутся к игроку (chase AI)
- [ ] Волны со временем усиливаются: растёт размер (количество/HP/скорость) и качество (новые типы монстров)
- [ ] У игрока есть оружие, автоматически атакующее монстров
- [ ] Монстры получают урон и умирают
- [ ] Убийство монстров даёт опыт (XP)
- [ ] Игрок прокачивает уровень по мере набора XP
- [ ] За каждый новый уровень выпадает выбор из 3 случайных способностей из пула
- [ ] Пул способностей ~40 штук
- [ ] Существуют способности, влияющие на прокачку уровня (XP gain / pickup range / etc.)
- [ ] У игрока есть HP; при HP <= 0 наступает Game Over
- [ ] Экран Game Over с возможностью рестарта

## UX / HUD
- [ ] HUD: полоса HP, текущий уровень, полоса XP, таймер выживания, счётчик убийств
- [ ] При level-up игра ставится на паузу и показывается выбор из 3 способностей
- [ ] Выбор способности мышью/клавишами, эффект применяется немедленно
