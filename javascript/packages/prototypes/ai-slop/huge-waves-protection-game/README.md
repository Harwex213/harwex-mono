# Huge Waves Protection Game

Браузерная игра-выживалка (клон Vampire Survivors). Управляешь героем, отбиваешься
от нарастающих волн врагов, качаешься и выживаешь как можно дольше.

## Стек

Plain HTML + ES modules + Canvas 2D. **Без шага сборки и без npm-зависимостей.**
Запуск через любой статический HTTP-сервер (ES-модули требуют `http://`, а не `file://`).

## Запуск

Из корня проекта поднять статический сервер и открыть в браузере.

```bash
# вариант 1
python3 -m http.server 8080

# вариант 2
npx serve .
```

Затем открыть http://localhost:8080 (для `serve` — порт из его вывода).

## Как играть

- **Движение:** `WASD` или стрелки (плавное, диагональ не быстрее прямой).
- **Атака:** автоматическая — оружие само стреляет по ближайшему врагу.
- **Старт:** на стартовом экране нажмите `Пробел` или кликните.
- **Level-up:** при повышении уровня игра встаёт на паузу и показывает 3 случайные
  способности — выберите кликом или клавишами `1` / `2` / `3`; эффект применяется сразу.
- **Game Over:** при `HP <= 0` — экран со статистикой; `Пробел` или клик — рестарт.

Цель: убивать врагов, собирать XP-гемы, прокачиваться (пул ~40 способностей: урон,
скорострельность, доп. снаряды, пробитие, скорость, HP/реген, радиус подбора, прирост
XP и др.) и выживать как можно дольше под нарастающими волнами.

## Структура

```
index.html              — точка входа, полноэкранный <canvas>
src/main.js             — bootstrap + game loop (фиксированный шаг симуляции)
src/core/state.js       — глобальное игровое состояние (createState)
src/core/math.js        — вектора, clamp, lerp, dist, len, norm
src/core/rng.js         — seedable детерминированный ГПСЧ (mulberry32)
src/core/input.js       — WASD/стрелки → нормализованный вектор движения
src/entities/player.js  — игрок: фабрика, движение, регенерация
src/entities/enemies.js — типы врагов (data-driven), масштабирование, chase-AI
src/entities/projectiles.js — снаряды (данные-объект)
src/entities/pickups.js — XP-гемы (данные-объект)
src/systems/spawn.js    — спавн волн (частота/размер/типы растут со временем)
src/systems/combat.js   — авто-атака, полёт снарядов, урон, смерть, контактный урон
src/systems/leveling.js — притяжение/подбор гемов, XP, кривая уровней
src/systems/abilities.js — пул ~40 способностей + выбор при level-up
src/render/renderer.js  — отрисовка сцены (только читает state)
src/render/camera.js    — камера следует за игроком; world↔screen
src/ui/hud.js           — HP, уровень, XP, таймер, счётчик убийств
src/ui/levelup.js       — оверлей выбора способностей (пауза)
src/ui/screens.js       — экраны start / game over + рестарт
```

## Архитектура

Фиксированный шаг симуляции (`dt = 1/60`) через accumulator: реальное время кадра
копится и «съедается» фиксированными шагами, что делает симуляцию детерминированной.
Есть защита от «спирали смерти» — не более 5 шагов симуляции за кадр.

Контракт слоёв: системы мутируют общий `state` в `update(state, dt)`; рендер только
читает `state`. Canvas тянется на весь экран и пересчитывается при resize с учётом
`devicePixelRatio` (картинка не размыта).
