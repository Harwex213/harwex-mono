Тени в 2D — три независимые задачи: контактные тени объектов, отбрасываемые тени от источников света, тень/туман видимости. Техники по возрастанию цены:

1. Спрайтовые (baked)

Отдельный спрайт-эллипс/скошенный силуэт под объектом, blend MULTIPLY или чёрный с alpha, отдельный слой ниже сущностей.
- Скос: тот же спрайт объекта, skewX, scaleY≈0.5, tint=0x000000, alpha≈0.35, ось у ног.
- Плюс: ~0 стоимости, батчится в один draw call.
- Минус: не реагирует на геометрию, не обрезается стенами.

2. Проективная геометрия (shadow polygon)

Для каждого затеняющего объекта и направленного «солнца» строится квад/полигон = силуэт, сдвинутый на L·dir, рисуется в отдельный RenderTexture-слой, затем композитится MULTIPLY поверх земли.
- Для тайлмапа: тень считается из тайлов-препятствий, полигон сливается (union по строкам) чтобы не было двойного затемнения от перекрытий.
- Двойное затемнение лечится: рисовать тени в offscreen-буфер белым/чёрным без альфа-накопления (blend: NONE или max), потом умножать один раз.

3. Shadow casting на CPU (visibility polygon)

Классика для точечных источников: берутся вершины всех блокирующих сегментов, лучи на вершину ±ε, сортировка по углу, построение fan-полигона видимости.
- O(n log n) на источник, n = число сегментов в радиусе.
- Сегменты для тайлмапа надо мержить (greedy meshing по граням), иначе n взрывается.
- Для сетки дёшево: recursive shadowcasting (Bresenham/octant-based) — целочисленный, идеален для FOV/тумана войны, даёт per-tile видимость, не полигон.

4. GPU: 1D shadow map (radial depth)

На источник: рендер расстояний до окклюдеров в текстуру 1×N или N×1 (углы по X, минимальная дистанция в R-канале), затем шейдер света сэмплит по atan2 и сравнивает дистанцию.
- Стоимость на источник: 1 маленький pass + 1 quad.
- Даёт мягкие тени (PCF по нескольким углам), масштабируется на десятки источников.
- Это стандартный подход у 2D-light-движков (Light2D в Godot, LÖVE light-world).

5. Light map композит

Общая схема для любого из 2–4:
1. Рендер сцены как обычно.
2. В отдельный RenderTexture рисуется освещённость: заливка ambient-цветом, поверх — источники аддитивно (ADD), тени вычитают/маскируют.
3. Финальный fullscreen quad: scene * lightmap (MULTIPLY).
- Лайтмап можно держать в 1/2–1/4 разрешения: тени мягкие, артефактов почти не видно, x4 экономия филлрейта.

6. Screen-space хаки

- SSAO-подобное: размытая альфа-маска высоты объектов, инвертированная, умножается на землю — даёт «прижатую» тень без геометрии.
- Height-map + фиксированный угол солнца: марш по высотной текстуре в шейдере (2.5D relief shadow), хорошо ложится на тайловый рельеф.

Практично для этого проекта (Pixi 8 + @pixi/tilemap, top-down)

- Слой shadows между ground и entities, всё в один Container с blendMode: "multiply" — батчинг сохраняется, пока текстура тени одна.
- Динамический свет: RenderTexture лайтмапа размером с вьюпорт/2, обновлять только при изменении камеры или набора источников; финальный композит — Filter/Mesh с кастомным фрагментным шейдером.
- Туман войны — отдельная сущность: per-tile видимость (recursive shadowcasting), в Texture формата R8 размера карты, апскейл с билинейной фильтрацией даёт мягкие края бесплатно.
- Не смешивать тени и туман в один буфер: у них разная частота обновления (тени — каждый кадр, туман — на движение юнитов).
