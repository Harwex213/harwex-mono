Песочница техник затенения в 2D: одна страница на технику, слева навигация.

`yarn workspace @hw/2d-shading dev` — порт случайный, печатается при старте.

## Устройство

| файл | роль |
| --- | --- |
| `src/registry.ts` | список техник = оглавление; `mount: null` — техника описана, демо нет |
| `src/main.ts` | hash-роутер: один монтированный демо за раз |
| `src/demos/*` | по файлу на технику, каждый владеет своим pixi-приложением |
| `src/lib/*` | общее между демо: сцена окклюдеров, hull, DOM-контролы |

## Правила

- **Демо возвращает teardown и в нём убирает всё своё** — pixi-приложение, тикер, DOM. Роутер
  других ручек не держит; забытый `app.destroy` = второй render-loop поверх первого.
- **Сцена одна на все демо** (`lib/scene.ts`, фиксированный сид). Техники сравнивают между собой,
  а не разные карты.
- **Новая техника = файл в `demos/` + запись в `registry.ts`.** Навигация из реестра строится сама.
