# Остров

Прототип по кор-луму из схемы: плавучий остров, который строится, растёт и держит волны с моря.

```
построил здания из доступных
        ↓ ветка развития, юниты, активные скиллы, пассивный доход
заказал юнитов и определил точку сбора
        ↓ армия для атаки и защиты
передвинул остров и захватил территорию, рискнув быть не готовым к волне
        ↓ территория под здания, уникальные здания, ресурсы
    ← назад к постройкам

отразил волну  → выжил, доход с убитых → в цикл
не отразил     → проигрыш
уничтожил босса → победа
```

## Как это работает в игре

**Территория.** Мир — сетка 5×4 секторов. Свой один, остальные видны, но чужие. Внутри сектора
клеточная сетка 10×10 под здания. Тип сектора решает, что на нём можно поставить: лесопилку — только
в лесу, шахту и обелиск — только на кристаллах, алтарь — только на руинах. То есть уникальные здания
физически недоступны, пока остров не дойдёт до нужной земли.

Стартовый сектор — лес, и это не украшение. Лесопилка ставится только в лесу, лес берётся только
экспансией, а экспансия стоит дерева. Начни на пустоши — и остров заперт навсегда: путь к двигателю
стоит 270 дерева плюс 110 на сам захват при 220 на старте и нулевом притоке. Ядро на всякий случай
даёт +0.5 дерева в секунду — если волна снесёт все лесопилки при пустом складе, отстроиться будет на
что.

**Движение острова.** Нужен «Двигатель острова». Дальше — клик по соседнему сектору и «Двинуть
остров»: сектор становится спорным, на нём появляются стражи (их тем больше и они тем крепче, чем
дальше сектор от старта). Пока армия их не перебьёт, захват не идёт. Когда стражи мертвы, земля
6 секунд пристаёт к острову. Волны в это время не останавливаются — это и есть риск из схемы.

**Волны.** Идут по таймеру, который сокращается с каждой волной (55 сек → 30 сек), а бюджет волны
растёт экспоненциально (×1.24 за волну). Состав пополняется по номеру волны: крабы → утопленники →
гарпунёры → отродья. Убитые платят золотом, и платят много: волна на 10 очков угрозы окупает башню.
Это главный источник дохода в середине партии — оборона должна кормить, иначе развиваться не на что.
Кнопка «Вызвать» запускает волну досрочно и поднимает награду на 40%.

**Босс.** Левиафан сидит в своём секторе и никуда не идёт. Захватить этот сектор нельзя — только
штурмовать. «Штурм босса» уводит всю армию на север, остров в это время остаётся на башнях и ядре.
Момент штурма выбирает игрок — как на схеме.

**Проигрыш** — разрушено ядро. **Победа** — убит Левиафан.

## Баланс, проверенный прогонами

Проверялось ботом, который играет честно: платит за всё, отстраивает разрушенное и штурмует босса,
набрав 13 рыцарей.

- Полная партия проходится: победа на 9-й минуте, 10-я волна, 13 рыцарей. Проигрыш тоже реален —
  два прогона из трёх умерли на 13–14-й волне, потратив золото на здания вместо армии.
- Пустой остров без единой постройки переживает волны 1–2 и умирает на 3-й (~3 минуты). Это окно на
  первую экономику.
- 20 мечников босса не берут (снимают ~25%). 10 рыцарей выигрывают впритык, 14 — уверенно. Лучников
  Левиафан переигрывает по дальности (210 против 170) — за него нужен ближний бой.
- Экономика держится на двух ресурсах, и оба успели побывать узким местом. Ранняя версия запирала
  партию по дереву, следующая копила 2000 неиспользуемого золота при нуле дерева. Текущие числа:
  ядро +2 золота и +0.5 дерева, рынок +4 золота, лесопилка +3 дерева.

## Стек и структура

React + `@preact/signals-react` + rspack + TypeScript, вся сцена — один canvas.

```
src/game/
  config.ts      весь баланс: здания, юниты, волны, экспансия, умения
  world.ts       структура мира, секторы, сетка занятости, проверки постройки
  game.ts        цикл с фиксированным шагом (1/60) и все команды игрока
  hud.ts         сигналы для UI + публикация снимка мира 10 раз в секунду
  sim/           экономика, здания, акторы, снаряды, волны, экспансия, умения
  render/        камера, статический слой земли, спрайты, основной проход
src/ui/          панели на сигналах поверх canvas
```

Разделение простое: симуляция живёт в обычных мутабельных массивах и не знает про React, рендер
читает их каждый кадр, а в сигналы уходит только то, что показывает HUD.

## Запуск

```bash
yarn workspace @hw/ostrov dev
```

В консоли доступен `window.ostrov` — тот же экземпляр игры. Нужен потому, что вкладка без фокуса не
получает кадров анимации: `window.ostrov.advance(1/60)` в цикле прокручивает симуляцию вручную.
