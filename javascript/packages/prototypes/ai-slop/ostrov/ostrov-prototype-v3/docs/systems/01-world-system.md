# World System definition

Весь мир состоит из гексагонов. Любой гексагон - воздух или земля. В мире существуют острова, от 6 до 25 клеток.

Типы гексов (`Hex`):
- `air`
- `land`

Гексагоны с типом `land` образуют острова (`island`). Остров включает от **10** до **60** гексов земли без разрывов.
