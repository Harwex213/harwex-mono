# Economics System definition

Гексы могут иметь здания (помимо юнитов). Типы зданий:
- Центр Власти
- Дающие производство (требуют ископаемые)
- Дающие еду (требуют ископаемые)
- Дающие металлы (требуют ископаемые)
- Население (генерирует население)
- Научные (генерирует очки науки)
- Военные (создаёт армии, даёт активные скиллы в бою, делает пассивную оборону)

Три ресурса:
- производство - увеличивает скорость производства зданий и юнитов
- еда - увеличивает рост жителей
- металлы - делает возможным создание войск

Ресурсы у игроков каждый свои.

Каждый гекс в игре содержит **ископаемые**. Они конечны, специальные здания их трансформируют в один из видов ресурса.

Центр Власти в игре у каждого игрока свой и один.
