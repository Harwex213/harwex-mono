# Units System definition

Гексы могут иметь юнитов. Юнит всегда принадлежит какой-то фракции. Игрок передвигает юнитов по карте. Типы юнитов:
- Поселенец (основывает Центры Власти)
- Строй-отряд (строит другие здания помимо Центра Власти)
- Армия (содержит боевых юнитов и порождает битвы при столкновении с вражеской армией)
